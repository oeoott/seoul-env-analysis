# seoul-env-analysis

🏙️ Green Seoul: 서울시 녹지 인프라와 대기질, 따릉이 이용의 상관관계 분석
본 프로젝트는 서울시 공공데이터를 활용하여 녹지 공간(공원)이 대기질 개선에 미치는 영향과, 환경 지표가 시민들의 친환경 교통수단(따릉이) 이용 행태에 미치는 영향을 통합적으로 분석하는 대시보드입니다.

📊 데이터 전처리 및 DB 구축
서울시 공공데이터 포털에서 수집한 3개의 이기종 데이터를 '자치구' 필드를 기준으로 통합하여 관계형 데이터베이스(seoul_env.db)를 구축했습니다.

데이터 정제 (Data Cleaning):

공원 데이터: 다중 헤더 구조를 단일화하고 분석에 불필요한 '소계' 행 제거.

대기질 데이터: '점검중' 등 비수치 데이터(String)를 산술 계산이 가능한 0으로 치환.

따릉이 데이터: 자치구별 대여 및 반납 건수를 합산하여 이용 활성화 지표 산출.

테이블 설계:

bike: 자치구별 따릉이 이용 현황

air: 자치구별 실시간 미세먼지(PM10) 농도

park: 자치구별 공원 면적 및 1인당 공원 면적

📈 주요 분석 및 비즈니스 인사이트
1. 자치구별 녹지 인프라와 공기질의 상관관계

분석 방법: JOIN을 통해 1인당 공원 면적과 평균 미세먼지 농도를 매핑한 산점도 분석.

인사이트: 인당 공원 면적이 넓은 자치구일수록 평균 미세먼지 농도가 낮게 형성되는 음의 상관관계를 확인했습니다. 이는 도시 녹지 확보가 실제 대기질 개선의 정량적 지표가 될 수 있음을 시사합니다.

2. 대기질 수준에 따른 따릉이 이용 변화

분석 방법: WITH절(CTE)과 CASE문을 사용하여 서울시 평균 미세먼지 농도를 기준으로 자치구를 그룹화한 후 평균 이용량 비교.

인사이트: 대기질이 '낮음(좋음)' 그룹에 속한 자치구의 따릉이 이용량이 '높음' 그룹보다 유의미하게 높게 나타났습니다. 이는 대기 오염이 시민들의 야외 활동 및 친환경 이동 수단 선택에 강력한 심리적 저항선으로 작용함을 보여줍니다.

3. 공원 면적 대비 자전거 이용 효율 분석

분석 방법: 공원 면적과 총 이용량을 결합하고, 면적 대비 이용 효율을 계산하여 버블 차트로 시각화.

인사이트: 녹지 면적은 넓으나 이용 효율이 낮은 지역은 자전거 도로 정비 및 대여소 추가 배치가 필요한 정책적 잠재 지역으로 식별할 수 있습니다.

🤖 AI 활용 (Vibe Coding)
본 프로젝트는 Google AI Studio를 활용한 '바이브 코딩' 공정을 준수했습니다.

데이터베이스 스키마와 분석 가설을 프롬프트로 전달하여 복합 SQL 쿼리(JOIN, CTE 등)가 포함된 Python 코드를 생성했습니다.

단순한 코드 생성을 넘어 데이터 시각화 결과에 대한 비즈니스적 해석(Insight)을 AI와 협업하여 도출했습니다.
